# Legacy screens

These four standalone HTML files predate the single-file `app.html` SPA
and are kept only as design history — they aren't served, aren't linked
to, and aren't part of any build.

- `landing.html` — original marketing landing (replaced by the `/` route in `app.html`).
- `login.html` — original standalone login screen (replaced by the `#/login` route in `app.html`).
- `dashboard.html` — original standalone dashboard (replaced by the `#/app` route in `app.html`).
- `design-system.html` — early Vitta design-system playground.

If you're looking for the live UI, it's `../app.html`. Delete this directory
whenever you're comfortable losing the history — nothing references it.
