# Build briefs — spec history

Four successive iterations of the product spec, kept for reference so the
"why" behind current design decisions stays discoverable. The v4 brief is
the most recent statement of intent; older versions capture what was
considered and dropped along the way.

- `build-brief-v1.md` — original scope.
- `build-brief-v2.md`
- `build-brief-v3.md`
- `build-brief-v4.md` — most recent; the aurora/navy design system this brief calls for is not what the current `app.html` uses (see `../adr/` for the actual decisions in force).

For architecture decisions and their rationale, see `../adr/`. The briefs
describe intent; the ADRs describe what was actually decided and built.
